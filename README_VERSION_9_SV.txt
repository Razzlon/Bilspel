TURBO & VÄNNER – VERSION 9

Det här är en uppdatering av ditt befintliga spel.

NYTT I VERSION 9
- Bilarna har fler detaljer: ögon, uttryck, leende front, speglar, lampor, racingrand, spoiler och mer detaljerade hjul.
- Huvudbanan är längre och bredare.
- Strandbanan och Äventyrsskogen har egna, lätt varierade kurvformer så att de inte känns exakt likadana som arenabanan.
- Banornas linjer och markeringar följer den valda formen.
- Dina sparade mynt, bilar och uppgraderingar från version 8 läses in automatiskt.
- Cache-versionen är uppdaterad så att mobilen hämtar de nya filerna.

SÅ LÄGGER DU IN UPPDATERINGEN PÅ GITHUB
1. Packa upp ZIP-filen på datorn.
2. Öppna ditt repository Bilspel på GitHub och se till att du står på main.
3. Ladda upp index.html, manifest.json och service-worker.js i repositoryts rot. Välj att ersätta befintliga filer.
4. Behåll icons-mappen och de tre PNG-ikonerna som redan fungerar. Om GitHub frågar, ladda inte upp en ny icons-mapp om den redan finns.
5. Commit changes direkt till main.
6. Vänta ungefär 1–2 minuter och öppna spelet igen. Stäng appen helt och öppna den på nytt om den gamla versionen visas.
7. Om du använder PWABuilder för APK:en behöver du paketera/publicera om appen för att få den uppdaterade versionen i installerad APK.

OBS
Detta är en förbättrad version av webbprojektet. Kontrollera spelet i webbläsaren först innan du bygger en ny APK.
